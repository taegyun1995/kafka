    본문과 별도로 Idempotency-Key 헤더를 보낸다. 같은 요청을 다시 보내려면 같은 키를 사용한다.

    동시 인원을 6보다 크게 넣어도 한 번에 6건까지만 나간다. 브라우저가 같은 서버로 여는 HTTP/1.1 연결을 6개로 제한하기 때문이다. 그보다 큰 수는 6개씩 나뉘어 전송되므로, 뒤 묶음은 앞 묶음이 저장된 뒤에 읽는다. 서버 안에서 진짜 동시에 돌리는 것은 보호 장치 실행 화면 쪽이다.

    세 상자는 꾸며 낸 애니메이션이 아니다. 01은 실제 HTTP 상태 코드, 02는 응답에 담긴 판정 결과, 03은 GET /reservation-rounds/{id}로 다시 읽은 저장 상태다. 보호 장치를 하나씩 켜며 무엇이 막히는지는 보호 장치 실행 화면에서 본다.
